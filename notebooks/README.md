# Companion notebooks

One notebook per chapter. Each code cell is a listing from the book, in book order, under the
same title. Start Jupyter from the repository root:

```bash
jupyter lab notebooks/
```

The first cell of every notebook switches to the repository root, so data paths such as
`data/grades.csv` work. Chapters 1–13 are saved with their outputs; Chapters 14–19 open desktop
windows, so run them on your own computer (not in Google Colab).
