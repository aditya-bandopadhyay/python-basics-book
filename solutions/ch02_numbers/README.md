## Short-answer hints

- **S1.** A single equals sign (`x = 5`) is an assignment operator that binds the name `x` to the value 5. A double equals sign (`x == 5`) is a comparison operator that checks equality and evaluates to `True` or `False`.
- **S2.** Floating-point numbers are represented in binary (base-2) format. Some base-10 decimals, like 0.1 and 0.2, cannot be represented exactly in binary with finite bits, causing tiny rounding errors when added.
- **S3.** Floor division (`//`) divides and rounds down to the nearest integer (e.g., `5 // 2` yields `2`). True division (`/`) performs floating-point division (e.g., `5 / 2` yields `2.5`).
