# Solutions

Worked solutions for the exercises in *Python by Curiosity*: every DIY task, every debugging
task, and every mini-project, plus the multiple-choice answers and short-answer hints
(also printed in Appendix F of the book).

**Try each exercise yourself before you look.** There is usually more than one good
answer; these are tested, readable ones.

Run the solutions from the repository root, for example:

```bash
python solutions/ch02_numbers/diy_2.py
python solutions/ch16_calculator/diy_1.py
```

Scripts that read data (Chapter 12) expect to be started from the repository root. The
Part III DIY solutions extend the chapter apps by importing them from `codes/`.
