## Short-answer hints

- **S1.** A compiler translates the entire source code into machine language at once, producing a standalone executable file before running. An interpreter translates and executes code line-by-line at runtime.
- **S2.** Humans have contextual knowledge, experience, and the ability to handle ambiguity. Computers are literal machines that only execute exact, predefined instructions.
- **S3.** (1) Finiteness: the algorithm must terminate after a finite number of steps; (2) Definiteness: each step must be clear and unambiguous; (3) Effectiveness: steps must be simple enough to be performed.
